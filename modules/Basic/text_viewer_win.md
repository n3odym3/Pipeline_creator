# Text Viewer Module

A multi-format terminal log window to inspect runtime text, dictionaries, or trigger statuses.

---

## Technical Specifications

- **Inputs**: `In` (Type: `TEXT`, `CMD_DICT`, or `TRIGGER`)
- **Outputs**: None.

---

## Usage

Connect any compatible text, command dictionary, or trigger pin to inspect incoming values in real time in a scrollable, read-only text block.
